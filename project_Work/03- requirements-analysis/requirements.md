## 2. Candidate Requirements
The system should allow some way to allow Volunteers to mark when they are/are not available to work 
The system should allow organizers to specify when a certain activity needs people with certain skills
The system should allow authorized users to post activities needing help and update those posts as time goes on 
The system should allow Volunteers to view all of their information that is being stored, and allow them to opt out of certain information being held if they feel is not needed
The system should allow Volunteers a way to sign in, and new Volunteers a way to register
The system should give Organizers a way to see a list of which Volunteers are attending an event/how many Volunteers are attending an event 
The system should have a way to allow Organizers to match Volunteers to an activity 
The system should give an option for Volunteers to drop out of an activity, as well as a notification to Organizers when a Volunteer drops out of an activity 
The system should have a singular area to store data in order to keep it secure 
The system should have an interface that trained users can feel comfortable using and accessing
